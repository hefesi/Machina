# Cognitive Loop

> **Status:** Teoria v0.1

O Cognitive Loop descreve a dinâmica recorrente pela qual o Virtual Brain percebe o ambiente, atualiza sua representação interna, pensa, age e aprende com os resultados.

## Loop principal

```text
PERCEIVE
   ↓
ATTEND
   ↓
INTERPRET
   ↓
RETRIEVE
   ↓
UPDATE WORLD MODEL
   ↓
UPDATE COGNITIVE STATE
   ↓
REASON / PLAN / DECIDE
   ↓
ACT
   ↓
OBSERVE OUTCOME
   ↓
DETECT SURPRISE / ERROR
   ↓
LEARN
   ↓
CONSOLIDATE MEMORY
   ↓
PERCEIVE AGAIN
```

## Princípio

O sistema não deve ser concebido como uma sequência linear que termina após uma resposta. A inteligência emerge da recorrência entre estado interno, ambiente, ação e feedback.

## Surprise

Quando a previsão interna diverge da observação:

```text
Expected State
      ↓
Actual Observation
      ↓
Prediction Error
      ↓
Surprise
      ↓
Investigation
      ↓
World Model Update
      ↓
Learning Event
```

A surpresa é uma fonte potencial de aprendizado e não apenas um erro.

## Investigação interna

Quando existe incerteza relevante, a Cognition pode gerar uma necessidade cognitiva:

```text
Uncertainty
    ↓
Question
    ↓
Memory Search / Observation Request
    ↓
Evidence
    ↓
Interpretation
    ↓
World Model Update
```

Isso permite comportamento investigativo.

## Continuidade

O loop deve preservar continuidade entre ciclos:

```text
State(t)
  ↓
Experience
  ↓
Feedback
  ↓
Learning
  ↓
Memory Consolidation
  ↓
State(t+1)
```

A continuidade de identidade depende da integração com Self e Memory.

## Integração

```text
Virtual Organism
       │
       ▼
   Perception
       │
       ▼
    Cognition ◄──────── Memory
       │                  ▲
       ▼                  │
   Reasoning              │
       │                  │
       ▼                  │
    Agency                │
       │                  │
       ▼                  │
     Action               │
       │                  │
       ▼                  │
   Environment            │
       │                  │
       └── Feedback ──────┘
```

O loop é a unidade dinâmica que conecta a arquitetura conceitual do Virtual Brain ao Virtual Organism.
