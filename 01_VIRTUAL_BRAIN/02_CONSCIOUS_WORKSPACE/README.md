# 02 — Conscious Workspace

## O presente cognitivo integrado do Virtual Brain

> **Pergunta fundamental:** O que está acontecendo agora e o que precisa estar disponível para o sistema pensar e agir?

O **Conscious Workspace** é o espaço funcional que integra, mantém e organiza o conteúdo relevante do presente cognitivo. Ele não é a memória persistente, não é o raciocínio e não é a agência.

O termo "conscious" é funcional: este documento não afirma consciência fenomenal. O Workspace é uma arquitetura de integração global que torna determinados conteúdos disponíveis para múltiplos processos cognitivos.

---

# 1. Função central

```text
PERCEPTION
    ↓
WORKSPACE
    ↕
MEMORY ↔ COGNITION
    ↓
AGENCY
    ↓
ACTION INTENT
```

O Workspace mantém o contexto ativo necessário para que diferentes sistemas trabalhem sobre uma representação compartilhada do presente.

---

# 2. Estrutura

```text
CONSCIOUS WORKSPACE
│
├── CURRENT CONTEXT
│   └── situação atual e contexto relevante
│
├── WORKING MEMORY
│   └── conteúdo temporariamente ativo para manipulação cognitiva
│
├── ACTIVE PERCEPTS
│   └── percepções atualmente relevantes
│
├── RETRIEVED MEMORIES
│   └── memórias recuperadas para o contexto atual
│
├── SELF STATE
│   └── representação contextual do Self
│
├── ACTIVE GOAL
│   └── objetivo atualmente em foco
│
├── COGNITIVE STATE
│   └── hipóteses, inferências e resultados relevantes
│
└── ACTION CONTEXT
    └── intenção e contexto necessários para a próxima decisão
```

A **Working Memory pertence ao Workspace**. Ela não é um tipo de memória persistente dentro de Memory.

---

# 3. Workspace ≠ Memory

```text
MEMORY
→ preserva informação ao longo do tempo.

WORKING MEMORY
→ mantém informação temporariamente ativa para processamento.

WORKSPACE
→ integra o conteúdo ativo do presente cognitivo.
```

Fluxo:

```text
MEMORY
    ↓ retrieval
WORKSPACE
    ↓ manipulation
COGNITION
    ↓ result
WORKSPACE
```

O conteúdo pode entrar e sair do Workspace sem ser apagado da Memory.

---

# 4. Workspace ≠ Cognition

```text
WORKSPACE
→ disponibiliza e integra conteúdo.

COGNITION
→ compreende, raciocina, simula, infere e resolve problemas.
```

O Workspace não raciocina sozinho. Ele fornece o contexto no qual Cognition opera.

```text
WORKSPACE
    ↓
COGNITION
    ↓
WORKSPACE
```

Reasoning é um processo interno de **Cognition**, não um sistema paralelo ao Workspace.

---

# 5. Workspace ≠ Agency

O Workspace mantém o objetivo ativo e o contexto atual. Agency decide o que perseguir e qual ação intencional deve ser emitida.

```text
SELF
→ valores e identidade

AGENCY
→ objetivos e prioridades

WORKSPACE
→ objetivo ativo e contexto atual
```

---

# 6. Self State

O Workspace recebe uma representação contextual do Self.

```text
SELF MODEL
    ↓
SELF STATE
    ↓
WORKSPACE
```

O Self Model é persistente. O Self State é contextual e pode mudar de acordo com a situação atual.

---

# 7. Integração com Memory

O Workspace consulta Memory quando precisa de informação que não está ativa.

```text
WORKSPACE
    ↓ query
MEMORY
    ↓ retrieval
WORKSPACE
```

Memory não deve inundar o Workspace. A recuperação deve ser seletiva, relevante e limitada pela capacidade cognitiva disponível.

---

# 8. Integração com Cognition

```text
WORKSPACE
    ↓ contexto
COGNITION
    ├── Understanding
    ├── Reasoning
    ├── Inference
    ├── Simulation
    └── Problem Solving
    ↓ resultados
WORKSPACE
```

O Workspace permite que resultados intermediários permaneçam disponíveis para outros processos.

---

# 9. Integração com Agency

```text
WORKSPACE
    ↓ contexto + estado + objetivo ativo
AGENCY
    ↓ decisão
ACTION INTENT
    ↓
ACTION SYSTEM
```

Agency não executa diretamente. O Workspace apenas mantém o contexto necessário para a decisão.

---

# 10. Ciclo global

O Workspace participa do ciclo cognitivo único do Virtual Brain:

```text
ENVIRONMENT
    ↓
VIRTUAL ORGANISM
    ↓
PERCEPTION
    ↓
WORKSPACE
    ↕
MEMORY ↔ COGNITION
    ↓
AGENCY
    ↓
ACTION INTENT
    ↓
ACTION SYSTEM
    ↓
VIRTUAL ORGANISM
    ↓
ENVIRONMENT
```

Novas observações retornam ao Workspace e iniciam uma nova atualização do presente cognitivo.

---

# 11. Conteúdo ativo

O Workspace deve priorizar:

- percepção relevante;
- contexto temporal e espacial;
- memórias recuperadas;
- Self State;
- objetivo ativo;
- estado emocional ou motivacional funcional, quando modelado;
- hipóteses atuais;
- incertezas;
- resultados intermediários de Cognition;
- contexto da intenção de ação.

Nem toda informação disponível no sistema precisa estar ativa simultaneamente.

---

# 12. Persistência e transitoriedade

```text
PERSISTENTE
├── MEMORY
├── SELF MODEL
├── WORLD MODELS
└── LEARNED STRATEGIES

TRANSITÓRIO
├── WORKSPACE
├── WORKING MEMORY
├── ACTIVE GOAL
└── CURRENT COGNITIVE STATE
```

O Workspace pode ser reconstruído após uma interrupção, desde que os estados persistentes necessários sejam preservados.

---

# 13. Contrato do Workspace

```text
PERCEPTION
→ fornece observações.

MEMORY
→ fornece lembranças e conhecimento recuperado.

SELF
→ fornece Self State.

COGNITION
→ transforma conteúdo ativo em compreensão e inferências.

AGENCY
→ recebe contexto e emite decisões e intenções.

ACTION SYSTEM
→ recebe Action Intent para execução.

LEARNING
→ utiliza experiências e resultados para produzir mudanças persistentes.
```

> **O Conscious Workspace é o presente cognitivo integrado: ele mantém o que está ativo, conecta sistemas especializados e permite que o Virtual Brain opere sobre uma representação compartilhada da situação atual.**
