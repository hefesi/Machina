# 02 — Conscious Workspace

Esta pasta será dedicada à teoria do espaço cognitivo global do Virtual Brain.

## Pergunta central

> Como informações relevantes se tornam disponíveis para integração, atenção, pensamento e tomada de decisão em um determinado momento?

O Conscious Workspace será estudado como o espaço funcional que integra informações relevantes de diferentes processos cognitivos e permite que o Virtual Brain mantenha um estado cognitivo atual.

A teoria deverá investigar:

- atenção;
- seleção de informação;
- contexto atual;
- pensamento ativo;
- intenção atual;
- integração entre processos;
- metacognição;
- monitoramento interno;
- relação com o Self;
- relação com memória e cognição.

O termo "conscious" descreve uma hipótese funcional de disponibilidade cognitiva global e não constitui, por si só, uma afirmação de consciência fenomenal.
