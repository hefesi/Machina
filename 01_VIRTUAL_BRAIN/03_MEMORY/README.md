# 03 — Memory

Esta pasta será dedicada à teoria da memória do Virtual Brain.

## Pergunta central

> Como o Virtual Brain armazena, recupera, organiza e consolida conhecimento e experiências ao longo do tempo?

O modelo inicial considera diferentes formas de memória:

- memória de trabalho;
- memória episódica;
- memória semântica;
- memória procedural;
- memória autobiográfica;
- memória prospectiva.

A teoria deverá investigar:

- formação de memórias;
- recuperação contextual;
- associação entre memórias;
- consolidação;
- esquecimento;
- atualização de conhecimento;
- conflitos e contradições;
- relação entre memória e identidade;
- preservação de continuidade sem impedir evolução.

A memória deve ser estudada como um sistema ativo que participa do pensamento e do aprendizado, não apenas como armazenamento passivo.
