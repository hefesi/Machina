# Experimentos

1. Memória — reutilizar experiências antigas.
2. Aprendizado contínuo — A → B → C sem destruir A.
3. Transferência — reutilizar estrutura em tarefa nova.
4. Auto-organização — observar criação/remoção/reorganização.
5. Generalização — testar problemas estruturalmente novos.

Sempre comparar com baselines simples e arquiteturas convencionais.

## Enquadramento na hipótese fundamental

Os experimentos devem testar mecanismos e relações relevantes à hipótese fundamental, com critérios observáveis e reprodutíveis. Priorizar estudos longitudinais de continuidade, memória autobiográfica, mudanças internas, atividade autoiniciada, autorregulação, formação e revisão de objetivos, acoplamento com ambiente e integração entre processos. Separar claramente evidência de autonomia funcional de qualquer inferência sobre consciência fenomenal. Ver [Hipótese Fundamental](../00-vision/central-hypothesis.md).
