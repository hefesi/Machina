# 08 — Agency

Agency governa objetivos operacionais, prioridades, decisões e intenções.

Separação:

`Self → valores/identidade`
`Agency → objetivos/prioridades/políticas`
`Workspace → objetivo ativo/contexto`

Agency não controla diretamente hardware ou APIs.

Fluxo:

`goal → candidate actions → prediction/simulation → evaluation → decision → action intent`

Mudanças de políticas aprendidas podem exigir validação antes da consolidação.
