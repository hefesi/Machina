# 07 — Self

O Self é o sistema funcional de autorrepresentação e continuidade.

```text
SELF
├── Self Core
├── Self Model
├── Self State
└── Identity Continuity
```

## Self Core
Elementos relativamente estáveis de identidade e princípios.

## Self Model
Modelo persistente e revisável de:
- capacidades;
- limitações;
- conhecimentos percebidos;
- recursos;
- padrões;
- trajetória.

## Self State
Representação contextual disponibilizada ao Workspace.

## Identity Continuity
Relações causais entre mudanças significativas na trajetória do sistema.

A arquitetura não afirma que esses mecanismos produzam consciência.
