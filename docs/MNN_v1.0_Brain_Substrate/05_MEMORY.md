# 05 — Memória

A memória não é reduzida aos parâmetros.

## Níveis

1. Operacional — contexto do ciclo atual.
2. Episódica — eventos e experiências.
3. Semântica — conhecimento consolidado.
4. Autobiográfica — trajetória do próprio sistema.
5. Procedural — estratégias e políticas aprendidas.

Fluxo de referência:

`experiência → operacional → avaliação → episódica → consolidação → semântica/procedural`

## Recuperação

A recuperação deve considerar:
- relevância;
- contexto;
- recência;
- confiança;
- relações no grafo;
- custo de recuperação.

Memória e estrutura neural devem poder evoluir de forma coordenada sem que uma seja simplesmente substituída pela outra.
