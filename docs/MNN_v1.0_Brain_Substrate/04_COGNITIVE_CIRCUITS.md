# 04 — Circuitos Cognitivos

As funções do Virtual Brain são mapeadas para subgrafos funcionais da MNN.

| Função | Realização |
|---|---|
| Perception | circuitos perceptivos |
| Working Memory | estado/contexto de curta duração |
| Memory | circuitos + memória persistente |
| World Model | representação dinâmica do ambiente |
| Self Model | representação persistente do próprio sistema |
| Cognition | associação, abstração, previsão, raciocínio e simulação |
| Planning | circuitos de sequência e avaliação de futuros |
| Agency | circuitos de decisão, objetivos e políticas |
| Learning | atualização paramétrica, conectiva e estrutural |

Os circuitos são funcionais, não necessariamente caixas isoladas.

## Reasoning

Reasoning é definido como processamento organizado de subgrafos ao longo do tempo:

`T_k = (G_k, Δt, Z_k, O_k)`

Um pensamento é tratado como um processo dinâmico observável, não como prova de experiência subjetiva.
