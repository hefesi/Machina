# 06 — Workspace

O Workspace é um mecanismo funcional de integração global.

Formalmente:

`W_t ⊆ V_t`

Ele representa uma coalizão temporária de unidades/subgrafos relevantes para o processamento atual.

Pode conter:
- observação relevante;
- memórias recuperadas;
- objetivo ativo;
- hipóteses;
- previsão;
- Self State;
- plano;
- incerteza;
- avaliação.

O Workspace não é Memory e não implica consciência fenomenal.
