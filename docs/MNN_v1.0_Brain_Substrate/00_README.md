# MNN v1.0 — Brain Substrate

A MNN v1.0 transforma a MNN v0.1–v0.9 em um substrato computacional para o Virtual Brain do Machina.

## Tese arquitetural

A MNN não é um módulo adicional do cérebro. Ela é o substrato dinâmico no qual percepção, memória, cognição, reasoning, planejamento, agência, self-model e aprendizagem podem ser realizados como circuitos e estados persistentes.

A arquitetura mantém uma separação entre:
- substrato neural dinâmico;
- modelos/memórias persistentes;
- funções cognitivas;
- interfaces com o organismo;
- mecanismos de aprendizagem e governança estrutural.

## Princípio central

`B_(t+1) = F(B_t, E_t, O_t, G_t)`

onde `B` é o estado estrutural e dinâmico do cérebro, `E` é experiência, `O` é resultado observado e `G` representa objetivos/contexto.

## Status

Esta versão é uma especificação de pesquisa. Ela não afirma AGI, consciência ou superioridade sobre arquiteturas existentes. Cada capacidade deve ser validada experimentalmente.
