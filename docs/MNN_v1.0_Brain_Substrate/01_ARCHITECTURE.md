# 01 — Arquitetura

```text
MACHINA
├── Virtual Organism
│   ├── Perception Interface
│   ├── Action System
│   └── Environment/Tools
│
└── Virtual Brain
    └── MNN Brain Substrate
        ├── Perceptive Circuits
        ├── Memory Circuits
        ├── Associative Core
        ├── Predictive Circuits
        ├── Reasoning/Simulation Circuits
        ├── Planning Circuits
        ├── Workspace
        ├── Self Circuits
        └── Agency Circuits
```

O cérebro é um grafo dinâmico, não um pipeline fixo.

`Input → Layers → Output` é substituído por ciclos recorrentes:

`observation → activation → retrieval → association → prediction → reasoning → evaluation → action → outcome → learning → structural update`.

## Enquadramento na hipótese fundamental

A arquitetura neural é uma hipótese de organização funcional do substrato MNN. Avaliar sua adequação por experimentos de dinâmica, integração, plasticidade, estabilidade e interação com os demais processos de Machina. A divisão em circuitos é instrumental e não deve ser confundida com uma explicação completa da mente ou da consciência. Ver [Hipótese Fundamental](../00-vision/central-hypothesis.md).
