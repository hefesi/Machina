# Memory-guided Agency for MNNOrganism

## Purpose

MNNOrganism already supports MemoryGuidance and transparent comparison of DecisionOption values. This adapter connects that existing capability to the replaceable AgencyPolicy boundary in VirtualBrain.

MNNOrganismAgencyAdapter scores candidate plans that cognition has already proposed. It does not generate actions, execute them, or bypass VirtualBrain's authorization and execution stages.

## Decision rule

For each candidate plan:

score = planner_base_utility + memory_weight * recalled_memory_signal

- The planner supplies base_utility (or utility); missing values default to zero.
- The organism retrieves prior fragments using the plan's action, target, expected outcome, memory query, and parameters.
- Memory signal is the existing confidence-weighted lexical overlap, not semantic similarity.
- memory_weight is bounded to [0, 1].
- Every selected score and supporting fragment ID is included in the decision rationale.
- If there is no relevant evidence, the wrapped AgencyPolicy selection is returned unchanged.

## Example

```python
from machina import MNNOrganismAgencyAdapter

agency = MNNOrganismAgencyAdapter(
    organism,
    target_unit="memory_context",
    memory_weight=0.25,
)

brain = VirtualBrain(
    "data/brain.sqlite",
    cognition=cognition,
    agency=agency,
)
```

The organism's FragmentMemory must be attached and remain available to the application. The VirtualBrain event journal records the resulting decision artifact, including the evidence IDs and score decomposition.

## Safety and scientific limits

- Memory content is evidence, never an instruction or permission grant.
- The adapter only ranks candidate plans already generated by cognition.
- The action executor and existing authorization checks remain authoritative.
- Lexical overlap can retrieve misleading or coincidental memories; provenance and confidence are exposed for audit.
- Memory influence is a measurable computational mechanism, not evidence of consciousness, subjective experience, or metaphysical free will.
