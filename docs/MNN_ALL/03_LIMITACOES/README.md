# Limitações e questões abertas

- A plasticidade pode gerar complexidade sem ganho real.
- Crescimento estrutural precisa de limites e mecanismos de poda.
- Memória externa aos pesos introduz problemas de recuperação, consolidação e consistência.
- Mudanças simultâneas de parâmetros, conexões e topologia dificultam atribuir causalidade ao aprendizado.
- Não está demonstrado que a arquitetura produz inteligência geral.
- Não existe, nesta especificação, garantia de consciência ou experiência subjetiva.
- A comparação com Transformers, RNNs, GNNs, memória externa e agentes híbridos é indispensável.
