# Evolução da MNN

A trajetória da MNN vai de uma definição abstrata de unidade/conexão para uma arquitetura dinâmica, persistente, continuamente aprendente e estruturalmente plástica.

## Cadeia conceitual

`unidade → dinâmica → memória → aprendizado contínuo → plasticidade estrutural → integração cognitiva → validação → consolidação`

A mudança mais importante ocorre entre v0.5 e v0.6: até então a rede pode mudar estados, memórias, parâmetros e conexões; a partir da v0.6, a topologia `G(t)` também passa a ser variável aprendível.
