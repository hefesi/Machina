# MNN v0.3 — Propagação e Dinâmica de Rede

## Objetivo
Definir como sinais percorrem a rede e como unidades e conexões interagem ao longo do tempo.

## Conexão
`E_ij(t) = [w_ij, r_ij, q_ij, h_ij]`

A conexão representa uma relação dinâmica, não somente um peso escalar.

## Mensagem
`M_ij(t) = F_M(x_i, m_i, E_ij, Z_t)`

## Ciclo
Entrada → propagação → atualização das unidades → atualização do estado cognitivo → saída/ação → feedback.

A arquitetura pode operar com ciclos internos e propagação síncrona ou assíncrona, que devem ser comparados experimentalmente.

## Critério de avanço
Definir uma dinâmica temporal reproduzível e identificar condições de estabilidade e comunicação eficiente.
