# MNN v0.7 — Integração Cognitiva Machina

## Objetivo
Integrar a MNN ao esqueleto cognitivo da Machina, sem assumir que os módulos cognitivos precisam ser implementados como blocos neurais convencionais.

## Mapeamento
- Perception → circuito perceptivo
- Working Memory → memória operacional
- Memory → memória episódica/semântica
- World Model → representação do ambiente
- Self Model → representação do próprio sistema
- Reasoning → processamento cognitivo
- Planner → sequências de ação
- Actor → ação
- Evaluator → avaliação/erro
- Learning → atualização paramétrica e estrutural

## Hipótese
A MNN deve servir como substrate dinâmico capaz de conectar percepção, memória, reasoning, planejamento, ação e aprendizagem contínua.

## Regra científica
A integração não prova AGI; ela cria uma arquitetura testável para investigar se a integração melhora desempenho e adaptação.
