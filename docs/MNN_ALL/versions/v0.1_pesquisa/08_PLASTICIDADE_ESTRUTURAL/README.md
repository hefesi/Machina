# Plasticidade Estrutural

A estrutura pode criar/remover unidades e conexões, fundir/dividir circuitos e especializar componentes.

Regra inicial: se o erro persistir acima de um limiar e a capacidade atual parecer insuficiente, a arquitetura pode propor expansão.

Mudanças devem ser avaliadas antes da consolidação.

Aprofundar: medição de insuficiência, geração de propostas, sandbox, reversão e controle de crescimento.
