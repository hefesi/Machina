# Memória

Separar memória dos pesos.

- Memória operacional: ciclo atual.
- Memória episódica: experiências (input, state, action, result, error).
- Memória semântica: conhecimento consolidado.

Fluxo: experiência → operacional → avaliação → episódica → consolidação → semântica.

Aprofundar: recuperação, consolidação, esquecimento controlado, interação com pesos e catastrophic forgetting.
