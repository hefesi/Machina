# MNN v0.1 — Linha de Pesquisa

Objetivo: desenvolver uma nova arquitetura neural projetada especificamente sobre o esqueleto cognitivo da Machina.

Hipótese central: uma rede neural dinâmica na qual unidades possuem estado/memória, conexões possuem plasticidade e parâmetros, conexões e estrutura podem aprender pode integrar melhor percepção, memória, reasoning, planejamento, ação e aprendizagem contínua.

Esta é uma hipótese de pesquisa, não uma alegação de AGI.
