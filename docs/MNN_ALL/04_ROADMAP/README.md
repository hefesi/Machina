# Roadmap pós-v0.9

## v1.0 — Arquitetura experimental consolidada

Objetivos:
- fechar as definições matemáticas;
- definir invariantes da rede;
- especificar algoritmos de atualização;
- definir mecanismos seguros de criação/remoção de estrutura;
- implementar um protótipo mínimo reproduzível;
- publicar protocolo de benchmark;
- comparar contra baselines.

A v1.0 deve ser uma especificação executável/implementável, não apenas uma descrição conceitual.
