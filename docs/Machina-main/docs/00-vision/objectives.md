# Objetivos

## Objetivo principal

Construir progressivamente um Virtual Brain capaz de integrar memória, raciocínio, aprendizado e ação em um ciclo cognitivo persistente.

## Objetivos do v0.1

1. Definir um modelo de dados cognitivo coerente.
2. Definir uma arquitetura de memória persistente.
3. Definir como pensamentos consultam memória.
4. Definir como experiências se transformam em aprendizado.
5. Criar um ciclo cognitivo observável e testável.
6. Separar conhecimento, memória, habilidades e estado atual.
7. Preservar histórico e evitar perda catastrófica de conhecimento.
8. Permitir substituição de componentes sem reescrever o sistema inteiro.

## Não objetivos do v0.1

O v0.1 não pretende:

- resolver AGI completa;
- simular integralmente o cérebro humano;
- permitir autoalteração estrutural irrestrita;
- treinar um modelo fundacional próprio;
- construir autonomia ilimitada.

## Critério de sucesso

O v0.1 será considerado funcional quando o sistema conseguir:

```text
Perceber uma situação
    ↓
Interpretar o contexto
    ↓
Recuperar memórias relevantes
    ↓
Raciocinar sobre o problema
    ↓
Formar uma decisão ou plano
    ↓
Executar uma ação
    ↓
Observar o resultado
    ↓
Avaliar o resultado
    ↓
Aprender e atualizar sua memória
```
