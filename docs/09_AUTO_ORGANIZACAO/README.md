# Auto-organização

Processo:
experiência → detectar padrão/limitação → propor alteração → testar → avaliar → consolidar/rejeitar.

Hipótese: a rede pode aprender não só parâmetros, mas formas melhores de organizar seu processamento.

Aprofundar: meta-controlador, critérios de utilidade e distinção entre evolução útil e complexidade inútil.
