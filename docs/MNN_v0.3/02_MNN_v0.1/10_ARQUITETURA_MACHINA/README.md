# Integração com Machina v2

A Machina v2 é o esqueleto cognitivo.

Mapeamento:
Perception → circuito perceptivo
Working Memory → memória operacional
Memory → memória episódica/semântica
World Model → representação do ambiente
Self Model → representação do próprio sistema
Reasoning → processamento cognitivo
Planner → sequências de ação
Actor → ação
Evaluator → avaliação/erro
Learning → atualização paramétrica e estrutural

Objetivo: definir uma topologia neural própria para esse esqueleto, em vez de simplesmente encaixar arquiteturas existentes.
