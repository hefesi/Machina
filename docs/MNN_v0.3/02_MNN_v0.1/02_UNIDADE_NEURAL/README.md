# Unidade Neural

Estado:
U_i(t) = [x_i(t), m_i(t), c_i(t), g_i(t)]

x = ativação/estado; m = memória local; c = confiança; g = contexto/objetivo.

A unidade recebe mensagens, entrada externa e contexto global e produz novo estado.

Aprofundar: função de atualização, memória local, confiança, objetivos, estabilidade e comparação com neurônios recorrentes, GRU e LSTM.
