# Princípios da MNN

1. Grafo neural dinâmico.
2. Unidade com estado.
3. Conexão como relação aprendível.
4. Estado cognitivo persistente.
5. Memória separada dos parâmetros.
6. Aprendizado paramétrico, conectivo e estrutural.
7. Evolução estrutural controlada.
8. Conhecimento não depende exclusivamente da topologia.
9. Mudanças estruturais são avaliadas antes da consolidação.
10. Toda hipótese deve ser testável.

Perguntas: essa organização melhora generalização? Qual o mínimo necessário? A plasticidade estrutural traz ganho mensurável?
