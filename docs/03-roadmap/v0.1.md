# Virtual Brain v0.1

## Objetivo

Construir o primeiro núcleo cognitivo funcional do Machina antes de buscar autonomia avançada.

## Escopo conceitual

### Incluído

- modelo de dados cognitivo;
- memória de trabalho;
- memória episódica;
- memória semântica inicial;
- recuperação de memória;
- contexto cognitivo;
- raciocínio baseado em LLM como componente;
- ações através de ferramentas;
- avaliação de resultados;
- aprendizado básico;
- consolidação de memória;
- observabilidade do ciclo cognitivo.

### Fora do escopo

- autoalteração estrutural automática;
- treinamento de modelo fundacional;
- autonomia irrestrita;
- consciência artificial como requisito;
- reprodução integral da cognição humana.

## Marcos

### M1 — Modelo Cognitivo

Definir entidades, relações e contratos de dados.

### M2 — Memória

Implementar formação, armazenamento, indexação e recuperação.

### M3 — Cognitive Loop

Executar ciclos completos de percepção até avaliação.

### M4 — Aprendizado

Converter resultados avaliados em atualizações persistentes.

### M5 — Avaliação

Criar testes para memória, recuperação, coerência, persistência e aprendizado.

## Critério de conclusão

Uma instância do Virtual Brain deve conseguir receber uma experiência, recuperar contexto relevante, raciocinar, agir, observar o resultado e aprender com esse ciclo de forma persistente.
