# Roadmap v0.10 — Chemical Signaling & Motivation

## Goal

Introduce a small, testable chemical-signaling layer that can modulate learning and action selection without replacing the MNN, memory, learning, agency, or self-continuity systems.

## Scope delivered in the first prototype

- Normalized, bounded state for four neuromodulator-inspired signals.
- Deterministic event-driven production and decay.
- Reward prediction error and running expected value.
- Explicit exploration, plasticity, and attention outputs.
- Versioned snapshot serialization.
- Unit tests for stability, deterministic replay, input validation, and expected signal behavior.

## Not claims

The names are biological inspirations, not one-to-one mappings to human neurochemistry. The prototype does not simulate molecular kinetics, subjective reward, or consciousness.

## Next experiments

1. Add a benchmark task where an agent can exploit an easy repeated reward or explore for long-term goal progress.
2. Compare identical baselines with chemical modulation enabled and disabled across fixed random seeds.
3. Measure task completion, cumulative goal progress, exploration efficiency, reward-loop frequency, retention, and compute cost.
4. Tune coefficients only against declared metrics and held-out scenarios.
5. Integrate modulation with the existing learning and agency contracts after benchmark evidence supports doing so.
