# Glossário

Unidade — elemento computacional dinâmico.
Conexão — relação aprendível entre unidades.
Estado — representação interna em um instante.
Memória operacional — informação usada no ciclo atual.
Memória episódica — experiências específicas.
Memória semântica — conhecimento consolidado.
Plasticidade paramétrica — mudança de parâmetros.
Plasticidade conectiva — mudança de conexões.
Plasticidade estrutural — mudança da arquitetura.
Estado cognitivo — representação integrada usada para processamento e ação.
MNN — Machina Neural Network.
